# QELZAVRYN — Ideas Without Boundaries

An independent digital-project portfolio featuring **PuzzlePanch**, **PaisaLens**, and **Cricket Lite**.

## Run locally

Open `index.html` in your browser. No build process or dependencies are required. An internet connection is used to load Google Fonts; system-font fallbacks are provided.

## Deploy to GitHub + Vercel

1. Create a repository (for example `qelzavryn`).
2. Upload the **contents** of this folder to the repository root.
3. In Vercel choose **Add New → Project**, import that repository, and use **Other** as the framework preset.
4. Leave the build command empty and deploy.

## Included

- `index.html` — homepage and project descriptions
- `style.css` — responsive styling
- `script.js` — mobile navigation and automatic copyright year
- `assets/qelzavryn-logo.webp` — brand artwork
- `favicon.png` — favicon
- `robots.txt`, `sitemap.xml` — add a sitemap after your final domain is known (see below)

## Before launch

- Check the two project URLs and descriptions against the latest live sites.
- Confirm the Qelzavryn brand name and trademarks before using it commercially.
- If you add a public contact email, add a mailto link in the Contact section. No email address has been invented here.
- After deployment, edit `sitemap.xml` to replace `YOUR-QELZAVRYN-DOMAIN` with your **actual** final hostname, and update `robots.txt` accordingly. Submit that sitemap to Google Search Console.
- `og:image` uses a relative path; for best social sharing support, change it to your absolute public URL after deployment.

This site deliberately does not include Moxima AMV.
